# 델타 규칙

`im-not-ai` 플러그인 v2.3.2의 `quick-rules.md` 71패턴에서 하우스 스타일(`~/.claude/output-styles/korean.md`)이 이미 덮는 것을 뺀 차집합이다. ID는 플러그인 taxonomy를 그대로 쓴다. 보고에서 규칙을 부를 때 이 ID를 쓴다.

이 파일은 플러그인에서 한 번 증류한 사본이다. 자동 동기화가 없으니 플러그인 taxonomy가 바뀌어도 따라오지 않는다. 갱신이 필요하면 그때 수동으로 다시 증류한다.

## 손대지 않는 것 (Do-NOT)

탐지와 교정 양쪽에서 제외한다. 하우스 스타일의 "정확도 우선"보다 목록이 구체적이므로 이쪽을 따른다.

- 고유명사, 제품명, 모델명, 기관명
- 수치, 날짜, 단위
- 큰따옴표 안 직접 인용, 인용 블록
- 법률 조문, 수학, 화학, 통계 표기
- 업계 표준 영어 약어: LLM, GPU, MCP, API, CLI 등
- 표준 technical term: prompt, token, pipeline 등. 기계적 직역 금지

## 내용 앵커

교정에 들어가기 전에 문장별로 주어, 목적어, 보어에서 원문의 주장을 이루는 핵심 명사와 개념어를 내부 목록으로 잡는다.

조사와 어미는 바꿔도 되지만 앵커의 원형 어휘는 결과에 최소 한 번 그대로 남긴다. 동의어 치환이나 문장 병합을 이유로 지우지 않는다. 수식어와 형식명사만 걷어내고, 앵커가 사라질 것 같은 교정은 그 문장째 되돌린다.

## A. 번역투

- **A-5** `~와 관련하여`, `~와 관련된` → `~에`, `~의`
- **A-6** `~에 기반하여`, `~을 바탕으로` 남발 → `~로`, `~을 보고`
- **A-8** 이중 피동 `~지게 된다` → 능동 또는 단일 피동. 하우스 스타일이 잡는 `~되어진다`의 다른 형태다
- **A-10** `~할 수 있다` 남발 → 단언으로. `높일 수 있다` → `높인다`
- **A-11** `~을 위해` 목적절 남발 → `~려고`, `~도록`, `~위한`
- **A-15** 추상 주어에 만능 동사(보여준다, 제공한다, 가져온다) → 구체 주어로 환원. 사역은 `~ 때문에`, `~ 덕분에` 부사절로. 인지 동사(suggest, show, indicate) 직역은 `~에 따르면 ~이다`로
- **A-18** 명사 앞 3어절 이상 관형구나 관계절이 왼쪽으로 길게 붙는 구조 → 문장을 나누거나 후치 동격절로. `X를 만났는데, 그 X는 ~`
- **A-4** `~라는 점에서` 3회 이상 → `~서`, `~라는 이유로`. 하우스 스타일의 형식명사 항목을 빈도 기준으로 조인 것이다

## B. 영어 병기

- **B-1** 한글에 괄호 영어를 매번 병기(`~(Sovereign AI)` 식) → 첫 등장만 병기하고 이후는 한글만
- **B-2** 설명 없이 낀 광고성 buzzword(seamless, robust, leverage) → 한국어로 풀어 쓴다. 표준 technical term은 위 Do-NOT대로 원어를 지킨다

## C. 구조

- **C-7** 문단 문두가 `먼저`, `반면`, `결국` 3단 공식으로 반복 → 접속사를 하나나 둘로 줄이거나 본문에 녹인다
- **C-9** 숫자 괄호 인덱싱 `1) 2) 3)` 나열 → 본문에 녹이거나 `우선`, `다음으로`로 변주. 하우스 스타일이 권하는 번호 목록은 실제 단계가 있을 때이고, 이건 산문 안에 인덱스를 뿌리는 경우다
- **C-10** 콜론 부제 헤딩 `X: Y`가 반복 → 헤딩을 단일 명사구로 압축. 학술 문서나 보고서의 실제 절 제목은 보존

## D. 관용구

- **D-3** 열거 도입구 `크게 세 가지로 나눌 수 있다`, `다음과 같은` → 도입구를 지우고 바로 본론으로
- **D-4** hype 어휘(획기적, 압도적, 파격적, 폭발적, 전례 없는) 3회 이상 → 구체 수치나 사실로 환원
- **D-6** 결말 공식 `~할 때입니다`, `~시점입니다`, `~할 순간입니다` → 구체 동사 단언으로. 문서당 1회 이하
- **D-7** 변환 공식 `X에서 Y로`, `X을 넘어 Y로` 반복 → 직접 단언으로. 문서당 1회 이하

## E. 격식

- **E-7** 청자 경어법 등급(해라, 하게, 하오, 해요, 합쇼)이 한 문서 안에서 섞임 → 하나로 통일한다. 어느 쪽으로 통일할지는 원문에서 우세한 등급을 따른다. 문서 전체의 경어 등급을 바꾸는 것은 이 규칙의 범위가 아니다

## F. 수식

- **F-4** 한자어 명사화 `-성`, `-적`, `-화`와 영어 명사화 직역이 문서에 12회 이상 누적 → 동사나 형용사 어근으로 환원. `정책의 시행` → `정책 시행`
- **F-5** `~적 N` 추상 체인(`전략적 함의`, `실천적 기반`) 3회 이상 → 명사끼리 붙이거나 풀어 쓴다. `전략 함의`, `실천의 기반`

## G. 완곡

- **G-1** 추측 종결 `~로 보인다`, `~로 판단된다`, `~라고 여겨진다`, `~인 듯하다` 남발 → 단언할 수 있는 곳은 단언
- **G-2** 이중, 삼중 완곡 `~할 가능성이 있을 수 있다`, `~로 보여질 수 있다` → 완곡을 하나만 남긴다
- **G-3** 균형 lexicon(`양쪽 모두`, `장점도 있지만`, `신중하게`, `균형`) 4회 이상 → 한쪽을 단언하거나 구체 비교, 조건부로 바꾼다

## H. 접속

- **H-3** 메타 진입구 `이는 ~`, `이 점에서`, `이 관점에서`, `이 말은` 3회 이상 → 본문에 녹이거나 지운다
- **H-4** `즉` 남발 → `곧`, `말하자면`으로 변주하거나 생략. 문서당 2회 이하. 하우스 스타일이 `즉`을 문두 접속사 연발 목록에 넣어 두었는데, 이건 그것을 빈도 상한으로 조인 것이다

## I. 형식명사

- **I-2** `주목할 점은`, `X은 ~라는 점에 있다` 형식명사 강조 → `X는 ~다` 직설로
